1. อุปกรณ์ MikroTik (3011 / 4011 / RBD52G)

1.1 ลอก Sticker เก่า และติด Sticker ใหม่ เขียนรายละเอียด (เลขที่วงจร / เลขครุภัณฑ์ / ยี่ห้อ,รุ่น / SN) พร้อมถ่ายรูปให้เห็น Sticker ชัดเจน

1.2 ทดสอบความเร็ว Port 2 และ Port 3 ไม่ต่ำกว่า 650 / 350 Mbps พร้อมเก็บผลทั้ง 2 ภาพ

2. ห้อง DLS / GPS / VICC (Access Point)

2.1–2.2 อุปกรณ์ AP (TOTOLINK / D-LINK / TP-LINK) ลอก Sticker เก่า ติด Sticker ใหม่ เขียนรายละเอียดครบถ้วน พร้อมถ่ายรูปเห็น Sticker ชัดเจน

2.3 ทดสอบความเร็ว WiFi & Port LAN:
• ห้องอบรม DLS: LAN 300/150M | WiFi 50/20M (SSID: DLS)
• ศูนย์เดินรถ GPS: LAN 350/200M | WiFi 50/20M (SSID: GPS)
• ตรวจสภาพ VICC: LAN 350/200M | WiFi 50/20M (SSID: VICC)
3. ห้อง GECC (มีขั้นตอนย้ายสาย & Authen)

3.1–3.2 ลอก Sticker เก่า ติด Sticker ใหม่บน AP ห้อง GECC พร้อมถ่ายรูปชัดเจน

3.3 ย้ายสาย LAN ที่ MikroTik จาก Port 5 หรือ 6 ➔ ไปยัง Port 4

3.4 ย้ายสาย LAN ที่ AP ห้อง GECC จาก Port WAN ➔ ไปยัง Port LAN ที่ว่างอยู่

3.5 ทดสอบเข้าใช้งานระบบ Authen WiFi

3.6 ทดสอบความเร็ว AP ประชาสัมพันธ์ GECC: LAN 300/150M | WiFi 50/20M (SSID: GECC)

4. เอกสารแบบส่งมอบงาน & ลงนาม

4.1 เขียนรายละเอียดวงจร + อุปกรณ์ (MikroTik และ AP ทุกห้อง) ลงในเอกสารแบบส่งมอบงานให้ครบถ้วน

4.2 ให้เจ้าหน้าที่ผู้รับผิดชอบ ลงนาม พร้อมประทับตรา ในเอกสารแบบส่งมอบงาน
